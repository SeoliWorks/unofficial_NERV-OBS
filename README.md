# 非公式 NERV-OBS ウィジェット

NERVの防災情報を、OBSの配信画面にリアルタイム表示するブラウザウィジェットです。

> **免責事項**
> 本ツールは特務機関NERVおよびDigitalGlobeとは一切関係のない、非公式の個人製作物です。本ツールを通じて一切の収益は発生しません。
> NERVの投稿情報は [unnerv.jp](https://unnerv.jp) から取得しています。

---

## できること

- 緊急地震速報・地震情報・津波警報・気象警報・火山情報をリアルタイムで取得
- 情報の種類や深刻度に応じた色分け表示（赤・橙・黄・青）
- 震度フィルター（例：震度3以上のみ表示）
- カテゴリの表示・非表示の切り替え
- 津波情報は常に優先表示するオプション
- 配信用の「本番モード」（設定ボタンを完全に非表示）
- 設定を埋め込んだ共有URLのコピー

---

## GitHub Pages版の利用方法

インストール不要です。OBS に URL を追加するだけで使えます。

### 1. OBS にブラウザソースを追加する

1. OBS を起動し、ソースの「＋」ボタンをクリック
2. **「ブラウザ」** を選択
3. URLに以下を入力

```
https://seoliworks.github.io/unofficial_NERV-OBS/
```

4. 幅・高さをお好みに合わせて設定（例：幅 400px、高さ 800px）
5. 「OK」をクリック

> **ヒント**
> 地震情報が書かれたカード以外の部分は透明なので、OBSで追加の設定をしなくても、配信画面にそのまま重ねて使えます。

## 設定の使い方

ウィジェット右上の **歯車アイコン（⚙）** をクリックすると設定パネルが開きます。

| 設定項目 | 説明 |
|----------|------|
| 接続状態 | サーバーとの接続状況を表示します |
| 最小震度 | これより小さい震度の地震情報を非表示にします（デフォルト：震度3） |
| 表示カテゴリ | 表示したい情報の種類を選択します |
| 最大表示件数 | 同時に表示する投稿数の上限（最大50件） |
| 津波情報を常に表示 | 津波関連の情報はフィルター設定に関わらず必ず表示します |
| 本番モード | 歯車アイコンを完全に非表示にします（配信中の操作ミス防止用） |
| 共有URLをコピー | 現在の設定を含んだURLをクリップボードにコピーします |

> **本番モードを解除するには**
> OBSのブラウザソースのURLから `kokokesu`というテキストを削除してください。

## 表示される情報の種類と色

| 色 | 深刻度 | 例 |
|----|--------|----|
| 赤 | 緊急（Critical） | 大津波警報、特別警報、緊急地震速報（警報） |
| 橙 | 警報（Warning） | 津波警報、気象警報、噴火警報 |
| 黄 | 注意（Advisory） | 津波注意報、気象注意報 |
| 青 | 情報（Info） | 地震情報、その他 |

## URLパラメーターで設定を固定する

OBSのブラウザソースのURLに以下のパラメーターを追加することで、設定パネルを開かずに動作を変更できます。設定パネルの「本番モードONの共有URLをコピー」ボタンを使うと自動的に生成されます。

| パラメーター | 値の例 | 説明 |
|---|---|---|
| `min` | `3` | 最小震度（0〜7, 5-, 5+, 6-, 6+） |
| `cat` | `eew,earthquake,tsunami` | 表示するカテゴリをカンマ区切りで指定 |
| `max` | `2` | 最大表示件数 |
| `tsunamiAlwaysShow` | `1` または `0` | 津波情報を常に表示するか |
| `kokokesu` | `1` | 歯車アイコンを隠すか |

**例：** 地震・津波のみ、震度4以上、本番モード
```
https://seoliworks.github.io/unofficial_NERV-OBS/?min=4&cat=earthquake,tsunami&kokokesu
```

## 接続の仕組み（参考）

1. 起動時に [unnerv.jp](https://unnerv.jp) の最新20件を取得して表示
2. WebSocket でリアルタイム受信（接続中は「リアルタイム接続中」と表示）
3. WebSocket が切断された場合、60秒ごとのポーリングに自動切り替え（「ポーリング中」と表示）
4. WebSocket の再接続を定期的に試みます

## 自分でホストしたい場合（上級者向け）

GitHub Pages 版ではなく、ローカルファイルや自前のサーバーで動かしたい場合のセットアップ手順です。

**必要なもの：** [Node.js](https://nodejs.org/) v18以上

### 1. リポジトリのクローン

```
git clone https://github.com/SeoliWorks/unofficial_NERV-OBS.git
cd unofficial_NERV-OBS
```

### 2. 依存パッケージのインストール

```
npm install
```

### 3. ビルド

```
npm run build
```

`dist/` フォルダが作成されます。OBS のブラウザソースで「ローカルファイル」を選択し、`dist/index.html` を指定してください。

### 動作確認（開発用）

```
npm run dev
```

ブラウザで `http://localhost:5173` を開くと確認できます。
